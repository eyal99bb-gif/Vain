# יועץ המסחר — Vain Trading

דשבורד ניתוח מסחר כן: משטר מרקוב 2.0 (מטריצת מעברים בדגימה ללא חפיפה),
מומנטום רב-אופקי, מסנן מגמה, חזרה-לממוצע ומשטר תנודתיות — משולבים לאות
אחד עם הסתברות היסטורית אמיתית וטווח אי-ודאות (Wilson 95%).

- **קריפטו חי** (ביטקוין, את'ריום, סולאנה) — ישירות מ-Binance/CoinGecko
  מהדפדפן, בלי מפתחות.
- **מניות ומדדים** דורשים שרת — בגרסה הסטטית הזו הם מוצגים על נתוני דוגמה
  עם אזהרה מפורשת.
- בקטסטים הם walk-forward בלבד, כולל עמלות, לצד קנייה-והחזקה.

## פיתוח

```bash
npm install
npm run test:quant   # 23 בדיקות מנוע
npm run dev          # http://localhost:3000/vain-trading/
npm run build        # יצוא סטטי ל-out/
```

הפריסה אוטומטית: כל push ל-main מריץ בדיקות, בונה ומפרסם ל-GitHub Pages
(ענף gh-pages).

**גילוי נאות:** כלי ניתוח בלבד. לא ייעוץ השקעות, לא הבטחת רווח. בקטסטים
מחמיאים — סחרו על נייר לפני כסף אמיתי.
